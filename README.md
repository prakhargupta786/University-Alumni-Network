# University-Alumni-Network

A web portal for the Botany Alumni Association, Ch. Charan Singh University, Meerut. It helps 500+ alumni register as members, view events, and stay connected with the association.

**Live site:** https://ccsubotanyalumni.in/

## Features

- Member registration and user authentication
- Event management (upcoming events and past events by the association)
- Executive body, general body and students sections
- Photo gallery and welfare scheme pages
- Donation page
- SQL Server database for alumni records, event registrations and membership data

- **Backend:** [ASP.NET Core / ASP.NET MVC], C#
- **Database:** SQL Server

## How to Run Locally

1. Clone the repository
```
   git clone https://github.com/<your-username>/botany-alumni-portal.git
```
2. Open the solution in Visual Studio
3. Run `database/schema.sql` in SQL Server to create the database
4. Update the connection string in `appsettings.json` with your own server details
5. Press F5 to run the project
